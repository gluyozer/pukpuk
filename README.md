# ИдеяБот 🤖

Чат-бот с нейросетью, который придумывает идеи для игр и разных проектов: игр, приложений,
Telegram-ботов, веб-сервисов, ИИ-проектов, DIY-устройств и творческих затей.

Нейросеть написана **с нуля на numpy** (GRU-языковая модель с ручным обратным проходом).
Никаких API-ключей, интернета, torch и GPU не нужно.

## Быстрый старт

```bash
pip install -r requirements.txt      # только numpy
python -m ideabot                    # интерактивный чат
```

Обученная модель уже лежит в репозитории (`ideabot/model/ideabot.npz`, 2,5 МБ). Если её удалить,
бот сам обучит новую при первом запуске (около 5 минут на 4 ядрах).

Проверено на Python 3.13 и numpy 2.5.

## Как с ним общаться

Можно писать обычными фразами:

```
Вы: придумай игру про космос и котов
🎮 Игра · «Горячая Лиса»   [космос + животные]
   Градостроительный симулятор про жизнь питомцев. Главный герой — бездомная
   собака с большой целью на заброшенной орбитальной станции. Время поджимает:
   кормушка почти пуста.
   • Фишка: мир реагирует на громкость твоего голоса.

Вы: 2 идеи для приложения про еду
Вы: хочу бота про музыку
```

Или командами:

| Команда | Что делает |
|---|---|
| `/игра`, `/приложение`, `/бот`, `/сайт`, `/ии`, `/железо`, `/творчество` `[тема]` | идея нужного вида |
| `/идея [тема]` | любой вид проекта |
| `/ещё` | повторить последний запрос |
| `/темы` | список тем (их 18: космос, море, лес, фэнтези, киберпанк, животные, еда, музыка, динозавры, роботы, зомби, ферма, детектив, время, сны, спорт, учёба, город) |
| `/креатив 0.3…1.5` | «смелость» идей: выше — страннее, ниже — аккуратнее |
| `/сохранить` | дописать показанные идеи в `favorites.md` |
| `/помощь`, `/выход` | подсказка, выход |

Можно назвать **две темы** сразу — получится смесь: «игра про море и роботов».
В одном сообщении можно попросить до 5 идей: «3 идеи для сайта про ферму».

Без интерактива (удобно для скриптов):

```bash
python -m ideabot idea -k игра -t "космос и котов" -n 3 --seed 1
python -m ideabot idea                 # одна случайная идея
```

## Как это устроено

```
lexicon.py ─► corpus.py ─► tokenizer.py ─► nn.py (GRU) ─► generate.py ─► bot.py
 словарь     шаблоны,       слова в         обучение      сэмплирование,  чат
 (вручную)   обучающие      номера          и модель      проверка
             идеи
```

1. **Корпус.** Из словаря (`lexicon.py`: 18 тем, 7 видов проектов, более 1100 вручную написанных записей)
   и таблицы шаблонов (`corpus.py`) каждую эпоху генерируется 12 000 новых идей — переобучиться нельзя.
   Треть идей — на стыке двух тем.
2. **Нейросеть.** Каждая идея — последовательность слов, начинающаяся с трёх служебных токенов:
   вид проекта и две темы. Модель (эмбеддинг 64 → GRU 192 → softmax по 2040 токенам, 672 тыс. параметров)
   учится предсказывать следующее слово. Обучение: Adam, обрезка градиента, ~5 минут.
3. **Генерация.** Бот задаёт модели вид и темы, а дальше она сама сочиняет название и текст
   (температура + nucleus-сэмплинг). За раз берётся несколько кандидатов.
4. **Проверка.** Нейросеть иногда склеивает середину одной фразы с концом другой и ошибается
   в согласовании («в городе, **которое** забыла карта»). Поэтому каждый кандидат проверяется:
   он должен целиком собираться из фраз словаря по шаблону вида, а название — быть грамматически
   правильным. Проверка строится из той же таблицы шаблонов, что и корпус, так что они не расходятся.

### Честно об ограничениях

- Это **маленькая модель, обученная на маленьком словаре**, а не ChatGPT. Она не знает ничего за пределами
  словаря и не понимает смысла: идеи — это осмысленно устроенные, но случайные сочетания
  («приложение про созвездия, которое превращает рутину в игру»). Как искра для вдохновения — работает;
  как готовое техзадание — нет.
- Новизна — на уровне **сочетаний**: ни одна из 200 проверенных идей не повторила обучающую выборку,
  но отдельные фразы берутся из словаря. Нейросетевые «склейки» новых фраз отбрасываются проверкой
  (по замерам около 4% сырых кандидатов).
- Тема распознаётся по ключевым словам (18 тем). Незнакомую тему («оригами») бот честно называет
  неизвестной и придумывает идею на случайную.
- Выбор между темами и видом — это то, чему нейросеть научилась; грамматику гарантирует проверка.

## Как расширить

1. Добавьте фразы или тему в `ideabot/lexicon.py` (формат — по соседним записям).
2. Переобучите: `python -m ideabot train` (флаги: `--epochs`, `--seqs`, `--hidden`, `--seed`).
3. Проверьте качество: `python -m ideabot eval`.

Если изменить словарь и забыть переобучить модель, тесты упадут с подсказкой.

## Качество и проверки

`python -m ideabot eval` на закоммиченной модели:

| Показатель | Значение |
|---|---|
| ошибка на новых данных (loss / perplexity) | 0,490 / 1,63 |
| идей, прошедших проверку (из сырых кандидатов) | 96% |
| идей по заданной теме (по словам темы в тексте) | 100% |
| уникальных идей в выборке из 200 | 200 |
| дословных копий обучающих идей | 0 из 200 |

Тесты (60 штук, ~10 секунд, только стандартная библиотека):

```bash
python -m unittest discover -s tests -t .
```

Они покрывают: градиенты нейросети (сверка с численным дифференцированием), совпадение пошаговой
генерации с обучением, обучение с нуля на маленькой модели, словарь и грамматику названий,
отбраковку склеек, разбор запросов (от 8 до 29 словоформ для каждой из 18 тем, 264 слова), чат (сценарии с заготовленным
вводом) и CLI (запуск процессом, в том числе через pipe).

## Структура

```
ideabot/
  lexicon.py    словарь: темы, жанры, механики, прилагательные
  corpus.py     шаблоны, генератор обучающих идей, проверка идей
  tokenizer.py  токенизация, словарь токенов, красивая сборка текста
  nn.py         GRU-нейросеть, Adam, сэмплирование (numpy)
  train.py      обучение
  generate.py   генерация с темами и отбором
  request.py    разбор фраз пользователя
  bot.py        консольный чат
  evaluate.py   замеры качества
  idea.py       структура идеи и вывод
  model/        обученная модель
tests/          тесты
```
